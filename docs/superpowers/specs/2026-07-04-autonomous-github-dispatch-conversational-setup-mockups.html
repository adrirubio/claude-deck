Conversational Team + Autonomy Setup — Mockups (Revised)

Supersedes the flow shape (not the individual autonomy-stage screens) from the earlier version of this document. That version assumed an AgentTeamPreset already existed and only walked through configuring autonomy on top of it. This revision fixes that assumption: the same conversation can start from zero — no team yet — and the brain proposes the team's composition itself, inspecting the target repo the same way it already inspects it for label routing, before flowing into the autonomy stages already designed.

If a team already exists for the repo the human names, the flow detects that and skips straight to the autonomy stages — the original mockups' starting point is now a fast path through this one, not a separate document.

Revision note: stage order is now Repo → Team composition → Labels & policy → Slot routing → Review. The last three are functionally the prior document's Stages 2–4, renumbered.

Changed: no longer nested in a preset

The old entry point lived inside an existing preset's Autonomy tab, which silently assumed a team already existed. The primary entry point now lives one level up, on the Agent Teams list itself — where "I don't have a team yet" is the normal starting state, not an edge case.

Why one slot, not a padded-out three-role roster: the brain's proposal here directly reflects "just me maintaining it" — a small solo project doesn't benefit from Architect/Backend/Frontend roles that don't correspond to real divided ownership. This is a deliberate contrast with Screen 3: composition inference should scale down as readily as it scales up, otherwise a human with a tiny repo gets a roster sized for a team that doesn't exist, and ends up doing more cleanup than the conversation saved them.
